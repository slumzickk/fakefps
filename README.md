## 📌 ภาพรวมโปรเจกต์

**SLUMZICK FAKEFPS** เป็นซอฟต์แวร์ที่พัฒนาขึ้นสำหรับ **จำลองการแสดงผลค่าอัตราเฟรม (FPS)** บนหน้าจอ โดยผู้ใช้งานสามารถกำหนดช่วงค่าต่ำสุด–สูงสุดได้ด้วยตนเอง รองรับค่าการแสดงผลสูงสุดถึง **5,000 FPS**

โปรแกรมนี้ถูกออกแบบมาเพื่อวัตถุประสงค์ด้าน:

- 🎬 **การสาธิต (Demonstration)**
- 📹 **การบันทึกวิดีโอ (Video Recording)**
- 🖥️ **การแชร์หน้าจอ (Screen Sharing)**
- 🎨 **การสร้างคอนเทนต์ (Content Creation)**

> ⚠️ **หมายเหตุสำคัญ:** ค่าที่แสดงโดยโปรแกรมเป็น **ค่าจำลอง (Simulation)** ไม่ใช่ค่า FPS จริงที่เกมหรือแอปพลิเคชันกำลังเรนเดอร์

## 📖 คู่มือการใช้งาน (Usage)

| ขั้นตอน | รายละเอียด |
|:---:|:---|
| **1️⃣ Launch** | เปิดไฟล์ **`SLUMZICK FAKEFPS.exe`** ขึ้นมา |
| **2️⃣ Authentication** | กรอก License Key `slumzick` แล้วกด **Continue** |

| **6️⃣ Stop** | กด **Stop** เมื่อต้องการหยุดการทำงาน |
